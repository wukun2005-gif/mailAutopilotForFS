3. 关键发现：照搬 reranker 会退化

patentExaminator 把基础分清零、只信 cross-encoder，是因为它的候选来自 RAG + 联网搜索两条异构通道，分数本来就不可比。而 deck 的候选全部来自同一个混合检索器，RRF 分数是有意义的信号 —— 抹掉它等于扔信息。照搬后实测：

修完数据卫生后复测为 2/5 —— 有改善，仍不达标。分数分布 0.05–0.88、无可用标定。试过 6 种喂给 reranker 的文本形态（整块 / 截 512 字 / section+body / 仅标题 / 前 240 字 / section+前 240 字），均无法稳定回到基线之上。

处置：remoteRerank 代码保留、链路接好，但 SILICONFLOW_RERANK_ENABLED 默认 false。理由与上述数据写进了 rerankStage() 的注释，避免以后被当成"没做完"。

4. 测试顺带暴露的数据卫生缺陷（已修）

中 HTML 注释正文混进 chunk

影响：embedding 与 rerank 都在给噪声打分。deck 幻灯片里带构建备注，例如某块正文中混进了 svg) must keep winning: freezing it with flex:0 0 auto…。

根因：stripTags() 用 <[^>]+> 去标签，<!-- 被当成标签吃掉，但注释正文与结尾的 --> 留了下来。

修复：先剥注释 .replace(/<!--[\s\S]*?-->/g,' ')。复验：该块 1155 → 1013 字，残渣检测通过。

中 dev plan 运维章节漏进知识库

影响：DEVPLAN_SKIP 想排除内部章节，但只有 评论系统 这一条，匹配不到「16.10 AI 自动回答观众评论」，于是该节作为无关问题的 top-1 浮了出来（实测出现在「AI 如何避免悄悄放宽权限」的重排 top-1）。

修复：加入 ^16[\.\s]，整章跳过。复验：共跳过 17 个内部章节，dev plan 78 → 66 块。
